# ci-cd-final-project

## Project Name
ci-cd-final-project

## Description
This project demonstrates the implementation of a CI/CD pipeline using GitHub Actions and OpenShift.

## Technologies Used
- Git and GitHub
- GitHub Actions
- Docker / Buildah
- OpenShift
- CI/CD Automation

## Project Objectives
- Automate application build and testing.
- Validate source code using automated workflows.
- Build container images.
- Deploy the application using OpenShift.
- Monitor application logs and deployment status.

## Conclusion
The ci-cd-final-project demonstrates an automated CI/CD workflow for building, testing, and deploying an application.
